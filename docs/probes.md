# Probe ledger

Every live probe run against an Enable Banking ASPSP for design purposes, not to collect
statements — one row per probe, kept regardless of whether the hypothesis held. `fetch-log.jsonl`
records the same requests, but it is `state/`: gitignored, per-machine, and not guaranteed to
survive a reinstall or a fresh clone. This file is the durable, public half.

**Scope.** ASPSP requests only — anything spent from the daily allowance a real `fetch` also draws
from. A probe against something else (for example the `apt-get install ofx` throwaway CI run in
[`adr-ofx-ci-conformance.md`](adr-ofx-ci-conformance.md)'s open question 1) does not compete with
that allowance and does not belong here.

**Convention.** A probe's requests carry a RunLog `command` tag of the form `probe-<slug>`
(`probe-designer` names it as part of the plan). `grep '"command": "probe-' state/fetch-log.jsonl`
finds every probe run on this machine and its request count; this file is what says, across
machines, what each one was for and what it settled. `adr-author` adds the row in the same PR as
the ADR that spent the probe; if the question turned out not to need an ADR, `doc-condenser` adds
it in the post-merge condense pass instead — this file never gets a row in the implementing PR
itself.

**Refutations get a row too.** A probe whose hypothesis was wrong is exactly the one somebody would
otherwise re-attempt, and its cost was just as real as a confirmation's.
